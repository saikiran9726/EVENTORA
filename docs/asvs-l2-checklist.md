# OWASP Application Security Verification Standard (ASVS) 4.0 — Level 2 Checklist

| Area / Control ID | ASVS L2 Requirement | Eventora Implementation & Verification Evidence | Status |
| :--- | :--- | :--- | :--- |
| **V1: Architecture** | Deny-by-default route configuration, explicit trust boundaries, threat modeling. | Every Fastify route validated on startup via `validateRouteSecurity` (`{ auth, policy, objectCheck }`). Unconfigured routes refuse to boot. | **PASSED** |
| **V2: Authentication** | Secure password hashing, brute force defense, credential rotation. | Argon2id (`m=65536, t=3, p=4`) with constant-time dummy verification on nonexistent users. Sliding window rate limiter throttles failed attempts to 5/min. | **PASSED** |
| **V3: Session Management** | Cryptographically secure tokens, cookie flags, idle expiry, instant revocation. | High-entropy 256-bit session tokens stored as SHA-256 hashes (`id_hash`). Cookies set `HttpOnly; Secure; SameSite=Lax`. Revoking session clears immediately. | **PASSED** |
| **V4: Access Control** | Principle of least privilege, anti-IDOR, tenant isolation, role governance. | Multi-tier RBAC (`student`, `reviewer`, `admin`) + capability assignments (`checkin`). Cross-tenant object substitution strictly rejected (403/404). Tested in `tests/security/idor-matrix.test.ts`. | **PASSED** |
| **V5: Validation & Sanitization** | Strict schema validation, parameter binding, XSS neutralisation. | Zod schemas validate all JSON payloads. 100% of SQL queries utilize parameterized `$1, $2` variables with `pg` driver; zero dynamic SQL string interpolation. | **PASSED** |
| **V7: Cryptography** | Secure random generation, timing-safe equality, verifiable credentials. | `crypto.randomBytes(32)` for tokens, `crypto.timingSafeEqual` for HMAC and CSRF verification. Certificates signed with SHA-256 hash and 12-char Crockford Base32. | **PASSED** |
| **V8: Error Handling & Logging** | No information leakage, structured logs, sensitive data redaction. | Global error handler strips SQL driver internals and stack traces. Pino JSON logs redact passwords, tokens, QR tokens, cookies, auth headers, and mask email addresses. | **PASSED** |
| **V9: Data Protection & Privacy** | Zero PII in public APIs, unguessable QR tokens, instant privacy controls. | QR tickets contain opaque 43-character tokens (`/t/<token>`), unguessable and non-enumerable. Public passports strip emails, phone numbers, and IDs. Private passports return indistinguishable 404. | **PASSED** |
| **V10: Communication Security** | HSTS, TLS enforcement, modern HTTP security headers. | HSTS `max-age=31536000; includeSubDomains; preload`, `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: strict-origin-when-cross-origin`. | **PASSED** |
| **V14: Configuration** | Hardened containers, non-root execution, read-only filesystem. | Multi-stage Dockerfiles running as unprivileged UID 10001 with read-only root filesystems and tmpfs. Environment validated by Zod at boot. | **PASSED** |
